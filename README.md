# Warenwirtschaft Web-App

Diese PWA enthält:
- Artikelverwaltung
- lokale Speicherung im Browser
- QR-/Barcode-Scan über die Handykamera, sofern der Browser BarcodeDetector unterstützt
- manuellen Code-Fallback
- Wareneingang, Warenausgang und Inventurkorrektur
- Gewinn-/Margenrechner ohne MwSt.
- JSON-Backup/Import

## Wichtig
Für Kamera und Installation als PWA muss die App über HTTPS oder localhost bereitgestellt werden.
Einfaches Öffnen der index.html als lokale Datei reicht für den Kamerazugriff in der Regel nicht.
